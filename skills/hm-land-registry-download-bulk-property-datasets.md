# Download bulk property ownership datasets

The middle tier of HM Land Registry's estate: self-serve to get a key, but licensed — and sometimes expensive — to get data.

## Before you start

Create an account at `https://use-land-property-data.service.gov.uk/registration` and an API key is issued automatically. Send it as the `Authorization` header on every request, and send `Accept: application/json`. Called without a key, every endpoint returns 403 with `{"error": "Access denied: You need to provide your API Key to perform this operation", "success": false}` — verified 2026-07-26.

A key alone is not enough to download. Each dataset carries its own licence which you must sign in the service, and some are chargeable: Registered Leases is £5,000 a year plus VAT, and the National Polygon Service — the boundary polygons and the title-number-to-UPRN lookup — is £20,000 a year plus VAT.

## Steps

1. **List what is available.** Call `listDatasets` (`GET /datasets`). Names include `ccod` (UK companies that own property in England and Wales), `ocod` (overseas companies that own property in England and Wales), `nps` (National Polygon Service) and `nps_sample`. The CCOD and OCOD names were renamed in the UI but the machine names and file names still use the old acronyms.

2. **Read the metadata before committing.** Call `getDataset` (`GET /datasets/{dataset_name}`). Check `fee` and `type` to see whether it is free or chargeable, `update_frequency`, `last_updated`, `file_size` and `format`, and `tech_spec_url` for the field-level specification. Note the two separate lists: `public_resources` (free sample files you can inspect without signing anything) and `resources` (the licensed files). Sample first, sign second.

3. **Understand the file naming.** Resources come in two shapes: `*_FULL_*` is a complete snapshot and `*_COU_*` is a change-only update. For an incremental pipeline, take one FULL then apply COU files; do not re-download FULL every month.

4. **Check history when backfilling.** Call `getDatasetHistory` (`GET /datasets/history/{dataset_name}`) for the list of historical files with sizes and dates. Be aware the structure changed: OCOD was published quarterly before November 2017, and CCOD was quarterly with a different structure before that date. Read the technical specification for the older files before parsing them.

5. **Mint the download URL and use it immediately.** Call `getDatasetFileDownloadUrl` (`GET /datasets/{dataset_name}/{file_name}`). It returns a pre-signed S3 URL with `valid_for_seconds: 10`. Ten seconds. Do not queue it, log it for later, or hand it to a scheduler — fetch it in the same execution, and re-mint if you need it again.

6. **Handle 403 as two different problems.** No key, or a key without a signed licence for that dataset, both surface as 403. Distinguish them by whether `listDatasets` succeeds: if listing works and downloading does not, the licence is the blocker, not the key.

## Error handling

The envelope here is not the Business Gateway envelope and not RFC 9457. Every body carries a boolean `success`; the payload is in `result` on success and a human-readable string in `error` on failure. See `errors/hm-land-registry-problem-types.yml`.
